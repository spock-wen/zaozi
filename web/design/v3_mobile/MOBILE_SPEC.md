## 1. 断点
| 条件 | 布局 |
|---|---|
| 宽 < 600 且竖屏 | 本稿手机布局：一屏一卡，不滚动 |
| 宽 ≥ 600，或 `(hover:hover) and (pointer:fine)` | 可显示键位说明（Space/Enter/K/←→/1–3），放在卡下一行小字或「?」浮层 |
| 宽 < 600 横屏 | 待定，先提示竖屏 |
键位说明只按「有键盘/精确指针」显示；触控设备一律用手势提示一行。

## 2. 竖向分区（以 360×760 可视区为例）
| 区 | 高 | 内容 |
|---|---|---|
| 顶部安全区 | env(safe-area-inset-top)，示意 28 | 系统状态栏 |
| 资源条 | 44 | 左：第 N 代记事人；右：骨片数、季节、菜单按钮 36×36 |
| 卡区 | 余量 | 卡片 + 左右选项字 + 手势提示 |
| 字匣条 | 110（含把手） | 已有字 52×52 + 主按钮「刻」高 44 |
| 底部安全区 | env(safe-area-inset-bottom)，最少 12 | — |

## 3. 卡片尺寸公式
- 卡宽 = 屏宽 − 2×18
- 卡高 = clamp(360, 可视高 − 安全区上下 − 44 − 110 − 60(选项字+手势行) − 24, 卡宽×1.45)
- 360×760 时约 324×468；卡片约占可视高六成。
- 卡内：来源行 13 / 标题 Serif 22 Bold / 正文 Serif 15/24 / 插画区自适应。

## 4. 提示浮层规则
- 不压正文：提示放在**卡底可收起区**（卡内底部，paper-100 底，上边 1px paper-line，Serif 13/20，最多 3 行）。
- 收起后只剩一行「提示 ▴」；展开时卡正文区不被遮盖（插画区先被压缩）。
- 字较多时改为卡外上方（资源条下）toast，2.5s 消失或点掉。

## 5. 组件
- **字匣条**：night-800 底、night-line 描边、圆角 16；顶部把手 36×4。点字 = 落字到卡；上拉 = 打开抽屉。
- **上拉抽屉**：高 ≈ 可视高 68%，paper-50 底，圆角 20 顶；分页「字录 / 骨片 / 日志」（分页条 paper-200）。字录格 60×60 同 v1 字录；日志按时间倒序、去掉内部编号。下拉、点遮罩（rgba(10,11,16,.62)）或返回键关闭。
- **菜单**：右上按钮打开，宽 250 浮层，paper-50。只列网页已有入口：导出存档码、导入存档码、字源与版权、种子显示。不新增功能。

## 6. 用户 6 个问题 → 解法
1. 卡片偏小、下面空白 → 卡片按公式占约六成高度，一屏不滚动。
2. 提示浮层挡卡面字 → 改到卡底可收起区或卡外 toast。
3. 手机显示键盘说明 → 按断点/指针类型隐藏，触控只留「左右拖卡做选择 · 长按看分量」。
4. 字匣/骨片/字录/日志平铺像调试页 → 字匣成底部窄条，骨片数进资源条，字录/骨片/日志进上拉抽屉。
5. 导出/导入存档挤在正文 → 移进右上菜单。
6. 不像游戏 → 一屏一卡、深色冬夜底、顶资源条 + 底字匣的游戏框架。
