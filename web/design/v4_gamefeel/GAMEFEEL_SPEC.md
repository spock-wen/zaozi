## 1. 参数表
### 1.1 拖动与提交
| 参数 | 值 |
|---|---|
| 提交阈值 | 横向位移 ≥ 卡宽 35%（沿用线上） |
| 倾角 | 位移/卡宽 × 15°，上限 15°；以卡底中心为轴 |
| 选项字透明度 | 位移 0→35% 映射 0→1；选项条盖住卡头 72 高（night-700 底、Serif 17 Bold） |
| 过阈值提示 | 屏幕对应边 6 宽金条（gold-400），出现 120ms ease-out |
| 回弹 | 320ms cubic-bezier(.34,1.56,.64,1) |
| 飞出 | 240ms ease-in，加转到 18°，透明度到 0 |
| 翻下一张 | 360ms cubic-bezier(.2,.8,.2,1)，Y 轴 180°，90° 时换面；翻完 120ms 内不接受拖动 |
| 按住看分量 | 300ms 触发（沿用 v2 SPEC），松手 160ms 淡出 |
| 电脑键盘 | ←/→ 一次：卡倾 8° 并显示圆点（160ms ease-out，不提交）；再按同向或 Enter 提交 |

### 1.2 圆点与飘字
| 参数 | 值 |
|---|---|
| 圆点位置 | 该维名正上方，底距维名 6 |
| 圆点大小 | 5 / 8 / 12 三档（沿用 v2 SPEC），gold-400，不表示涨跌 |
| 圆点出现 / 消失 | 120ms 淡入；提交或回弹时 160ms 淡出 |
| 数字 | 一直显示；提交后数字与条长一起滚到新值 400ms cubic-bezier(.2,.8,.2,1) |
| 飘字 | 「+8」「−4」，13 Bold；涨 #8FB8A8、跌 #E08A74（深底上均 ≥4.5:1）；从维名上方 0 → −16 位移，600ms，前 400 不透明后 200 淡出 |
| 危险区 | 数值 ≤15 或 ≥85：维名与条变 #E08A74（阈值为版式示意，以玩法为准） |

### 1.3 落字 / 刻字 / 演变
| 参数 | 值 |
|---|---|
| 可落提示 | 卡底虚线落点 56 高「可落字：X」；字匣里可落的字金色外圈呼吸 1200ms 一周期，2 次后停 |
| 飞字 | 放大到 1.4，弧线飞到落点 280ms cubic-bezier(.2,.8,.2,1) |
| 落定 | 盖印下压 scale 1.12→1，120ms；之后受影响维度飘字 |
| 原格 | 变虚线「已落」，本代不能再当部件 |
| 刻字 | 点骨片 → 已刻态（v3 四态）；顶部「骨片」小签飘「−1」 |
| 演变进一格 | 卡上浮演变条（卡内，不超卡宽）；新格先描朱色外圈 240ms，再亮底 200ms；下一格 35% 透明预告；停 1600ms 后收起 |

### 1.4 目标
| 参数 | 值 |
|---|---|
| 位置 | 手机：顶部「目标 ●○○」小签（点击区 44）；电脑：侧栏顶部常驻，收起时同手机小签 |
| 开春展开 | 每代第一张卡内展开三件事，1600ms 后 320ms 收进小签 |
| 达成 | 卡外提示条 44 高，手机从顶部滑下、电脑从右上滑入；停 1800ms；圆点空→实并 1.3→1 放大 240ms；**等飘字结束后再出**，避免压住数值 |
| 清单 | 点小签弹出 264 宽清单；点暗处关 |

### 1.5 出发挑字
| 参数 | 值 |
|---|---|
| 候选 | 字录里的字；手机 4 列 72×88，电脑 5 列 |
| 看说明 | 手机点一次；电脑悬停即显示右侧说明 |
| 选中 | 再点一次：变朱底、角标序号；副本飞入空格 280ms，入格下压 120ms |
| 取消 | 点已选字或格内字：飞回 200ms ease-in-out，后面左移补位 160ms |
| 选满 | 其余降到 40%（仍可点，点了提示「先放回一个」并抖格子 2 次共 240ms）；出开局判语；按钮变朱 |
| 电脑键位（新增建议） | ← → 移动、Space 选（字池 14 字，数字键不够用）、Backspace 放回最后一个、Enter 出发 |

## 2. 音效清单（只写方向，不出音频）
| 时刻 | 音色 | 时长 |
|---|---|---|
| 拖动过阈值 | 很轻的木片擦过声，一次 | 80ms |
| 提交（飞出） | 纸卡快速掠过的「嗖」，低音量 | 180ms |
| 回弹 | 软的木头回位「嗒」 | 100ms |
| 翻下一张 | 厚纸翻面声 | 220ms |
| 数值涨 | 两个上行的木琴短音 | 240ms |
| 数值跌 | 一个低的闷鼓短音 | 200ms |
| 进入危险区 | 低沉的单下埙音 | 400ms |
| 落字 | 骨章按在湿泥上的闷「噗」+ 短余响 | 260ms |
| 刻字 | 刀尖在骨上刮两下 | 320ms |
| 演变进一格 | 一声清的磬音，渐弱 | 600ms |
| 目标达成 | 三连短木铃，上行 | 480ms |
| 挑字选中 | 刻木「笃」 | 120ms |
| 挑字取消 | 更轻、更高的「笃」 | 100ms |
| 选满 / 出发 | 低鼓一声 + 风声起 | 800ms |
| 一代结束 | 长风声渐弱 + 单下钟 | 1600ms |
音量分三层：操作反馈（−18dB）< 结果（−12dB）< 里程碑（−8dB）。同一时刻最多两声。设置里要有静音（线上无此入口，待定）。

## 3. 状态说明
- **静止**：数字、条可见；无圆点。
- **拖动 <35%**：圆点、选项字半显；数字不变。
- **拖动 ≥35%**：选项字全显；边缘金条。
- **提交**：飞出 → 数值滚动 + 飘字 → 翻牌 → 可再拖（共约 720ms）。
- **回弹**：圆点淡出，不改数值。
- **可落字 / 落字 / 落定 / 刻字 / 演变**：见 1.3。
- **教学 1–5 + 先人**：见 gf3；每张只教一件事，提示条在卡与字匣之间（手机）或卡右侧外（电脑），不压卡面。第 3 张锁左右拖直到点骨片；第 4 张教学期借一个「水」。
- **目标**：开春展开 / 平时小签 / 达成提示 / 清单。
- **挑字**：未选 / 看说明 / 选中 / 取消 / 选满 / 出发。

## 5. 需要程序员确认
1. 线上圆点在画布里（y≈470），数值条在 DOM 里；把圆点挪到条上方要跨画布和 DOM，还是整条改进画布。
2. 翻牌和飞出能否用 CSS transform 做，还是画布内自己画；低端机能否 60fps。
3. 电脑 ←/→ 改成「先预览再提交」会改变线上键位行为（线上 ←→ 是「选」），要确认是否接受；Enter 和 K 现在都标「刻」，是否同义。
4. 教学卡固定顺序要在 `data/*.json` 加字段（研究稿推断），第 3 张锁拖动需要引擎支持。
5. 每代目标、挑字界面、多代传承目前引擎都没有（研究稿第四、五节），要先排玩法。
6. 音效用 Web Audio 合成还是做音频文件；静音入口放哪。
7. 达成提示与飘字的先后顺序（本稿：飘字结束后再出）。
8. 挑字界面传下事签占 1 格（玩法稿 §4.2）怎么画，本稿未画。
9. 减少动态（prefers-reduced-motion）：建议倾斜、飞出、翻牌都改为 120ms 淡入淡出。
