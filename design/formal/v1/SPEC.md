## 3. 布局尺寸（360vp 屏宽）

- 间距阶梯：4 / 6 / 8 / 12 / 16 / 20 / 24。
- 页面左右边距：冬夜页 16；字录页 12。
- 卡片：内边距 16，圆角 16，描边 1 `#D8CCB2`。弹层：上圆角 20，内边距 20，顶部把手 36×4。
- 骨片（造字卡）：328 × 356，四角不等圆角 `30 22 34 20 / 22 32 22 30`，内阴影 + 外阴影 `0 10 24 rgba(0,0,0,.35)`；字形区 176 × 176，距顶 22。
- 区块之间：分隔线上下各 14–16。
- 字录格子：60 × 60，圆角 12，间距 9，一行 5 格（336 宽）。
- 「设计稿，非玩法示意」：每个屏幕顶部 24 高朱色条 + 稿头右上角徽标；正式包里删掉。

## 4. 三套界面：组件与状态

### 4.1 造字卡（造字那一刻）
组件：状态栏（代次 / 空骨片 / 字录计数）· 冬夜标签（gold 描边胶囊）· 事签（Serif 14）· 骨片（字形区 + 公式行 + 卡面档演变条）· 跳过提示 · 进度点 · 成字弹层（标题、造法、数值条「记 +6」、骨片说明、看字录 / 继续）。

| 状态 | 说明 |
|---|---|
| 播放中 | 古字形用刻痕色；演变条已播到的格常亮，当前格朱色 2 描边，没播到的格透明度 38% |
| 落定 | 今天的字用墨色 ink-900，演变条最后一格选中 |
| 弹层 | 遮罩 45% 黑，弹层上滑 240ms |
| 重看 | 约 1 秒：甲骨文 400ms → 今天写法 600ms |
| 跳过 | 点一下任意处 → 落定 + 弹层 |

节奏（首次约 3 秒）：0.0 甲骨文描边生长 480ms → 0.6 金文 → 1.2 小篆 → 1.8 隶书 → 2.4 今天写法 → 3.0 弹层。阶段之间交叉淡化 300ms；某阶段没有字形就跳过，不停顿，总时长相应缩短。
复用：会意写两个部件（`人 + 木`）；象形写「描迹」；指事写「底字 木 · 一在其下」。造法徽标：会意朱、象形青、指事紫灰。

### 4.2 字录详情
组件：导航（返回 / 标题 / 计数胶囊）· 分页条（全部 / 象形 / 会意 / 指事，带计数）· 详情卡（大字方块、造法徽标、部件、造于 + 记事人、「再看一次」）· 白话字义 · 典籍（引文竖线 + 出处）· 古字形演变（标准档演变条，可点）· 小故事 · 效果（落字 / 解锁 / 部件标签行）。
空着的情况：典籍查不到 → 整块不显示；某阶段没有字形 → 那一格不出现。

格子四种状态：

| 状态 | 外观 |
|---|---|
| 已造 | paper-50 底，1.5 描边 ink-600，今天的字 Serif 30 Bold |
| 有事签 | 透明底，1.5 虚线 ink-600，问号 + 「有事签」10 |
| 有残片线索 | jade-100 底，1.5 描边 jade-600，问号 + 摆对的一半（如「木 + ？」） |
| 未知 | paper-200 底，无描边，问号 `#A99F8D` |
| 选中 / 新造 | bone-100 底，2 描边朱色；「新」角标 16 高，第一次点开后消失 |

## 6. 字体与字形

- 今天的字：Noto Serif CJK SC（繁体格 Noto Serif CJK TC），SIL OFL 1.1，box 上 Debian 包 `fonts-noto-cjk`。UI 文字：HarmonyOS Sans SC。
- 古字形：只用有出处的文件，笔画不改，粗细不拉齐。显示版只改 SVG 根标签的 viewBox（PNG 只裁边加透明边），让最长边占 86%。脚本：`glyphs/norm.py`。
- 颜色：SVG / PNG 都当蒙版用，颜色走 token（浅底刻痕色、深底 glyph-night）。鸿蒙端可用 `Image().fillColor()`（只对 SVG 生效）；PNG 用 `colorFilter`。

## 7. 待工程确认

1. 古字形粗细差别大（甲骨文细、金文粗）。要不要统一加一层很细的同色描边？本稿没有加（加了等于改字形样子），先请工程和美术一起看真机效果。
2. SVG 当蒙版上色：鸿蒙 `Image.fillColor` 会替换 SVG 里所有可绘制元素的填充色，需真机确认 Commons 文件（有的带 stroke）上色后没有缺笔。小学堂隶书是 PNG，要走 `colorFilter`。
3. 造字动画的交叉淡化和描边生长：描边生长需要逐笔中心线，Commons SVG 是填充轮廓，没有中心线。退路：用从下往上的遮罩擦出代替描边生长。
4. 白话 10fp 两行在小屏上是否够大；不够就把标准档格子加到 60，演变条改成两行排。
5. 字录总数写的是 27（首版必收），如果字录按 60 格展示，计数和格子行数跟着改。
6. 「设计稿，非玩法示意」标注只在设计稿里，正式包不带。
